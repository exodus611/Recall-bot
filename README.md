# 🚨 «Отзывы Израиль» — бот изъятий продукции на русском

Автоматический мониторинг отзывов (изъятий) продуктов и товаров в Израиле → русская карточка → пуш в Telegram + страница на сайте. **Полный автомат: работает сам, сервер не нужен, costs 0 ₪.**

## Как это устроено

```
Источники (каждые 20 минут, GitHub Actions — бесплатный будильник):
  1) Gov.il — лента Минздрава (прямой опрос; если Cloudflare блокирует — пропускает)
  2) Google News RSS — «החזרה יזומה / ריקול» за 30 дней (стабилен, без ключей)
        ↓ дедупликация
Словарь ивритских формулировок (без ИИ): причина, категория, бренд, «детское»-флаг
        ↓
Карточка на русском
        ├── 📨 Telegram (пуш в канал через Bot API — без сервера)
        └── 🌐 страница сайта (site/*.html) — SEO-дверь «нутрилон отзыв израиль»
База: data/db.json (git хранит всю историю, бесплатно)
```

**Приватность по конструкции:** бот ничего не спрашивает, ничего не хранит о читателях, никому ничего не пересылает.

**Медиа-политика (100% легальность):** никаких чужих фото и логотипов — ни в Telegram, ни на сайте. Только текст, наши эмодзи-иконки и ссылка на первоисточник. (Февральская правка: картинки статей СМИ убраны — обложки статей не всегда изображают сам продукт и являются объектом авторского права.)

## Файлы

| Файл | Что делает |

## Запуск (30 минут, один раз)

1. **Бот:** в Telegram у @BotFather → `/newbot` → имя `Отзывы Израиль • Изъятие продуктов RU`, username типа `otzyv_il_bot`. Получите токен.
2. **Канал:** создайте публичный канал (например `@otzyv_israel`), добавьте бота **администратором с правом публикации**.
3. **Репозиторий:** загрузите эту папку в новый GitHub-репозиторий (можно private).
4. **Секреты:** Settings → Secrets and variables → Actions, добавьте:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather
   - `TELEGRAM_CHAT_ID` — `@имя_канала`
   - `SITE_BASE_URL` — (необязательно) ссылка на бота/сайт для подписи
   - `HEALTHCHECK_URL` — (необязательно) URL с healthchecks.io: будет письмо, если монитор замолчит
5. **Первый запуск:** вкладка Actions → «recall-monitor» → Run workflow. **ВНИМАНИЕ:** первый реальный запуск сделайте со строкой `python src/monitor.py --bootstrap` (или один раз локально) — иначе бот разом опубликует все объявления за 30 дней. Bootstrap запомнит их молча, дальше публикуются только новые.
6. Всё. Дальше: cron проверяет каждые 20 минут, новые отзывы уходят в канал, база и сайт коммитятся автоматически. GitHub пришлёт письмо, если монитор упадёт.

## Локальный тест

```bash
python3 src/monitor.py --dry-run     # посмотреть карточки в консоли
python3 src/monitor.py --bootstrap   # первый импорт без публикации
open site/index.html                 # сгенерированный сайт
```

## Сайт

Папка `site/` — готовый статический сайт (index + страница на каждый отзыв).
Варианты публикации: GitHub Pages (бесплатно), Cloudflare Pages, или просто залить на ваш существующий хостинг в подпапку. Каждая карточка — отдельная страница с SEO-заголовком («Отзыв: … — Отзывы Израиль») — это дверь из Google.

## Легальность и «обходные пути» — нет их

- **Google News RSS и RSS Ynet** — официальные публичные фиды, созданные именно для программного чтения (кнопки/документация «RSS» на этих сервисах). Их использование — норма, так работают все агрегаторы.
- **gov.il**: код делает обычный запрос страницы. Если Cloudflare просит браузерную проверку — код **отступает** и берёт те же официальные объявления из зеркал. Никакого разгадывания капч, подмены браузеров, прокручек и логинов в коде нет.
- **Факты** (продукт, партии, даты, причина) авторским правом не охраняются; перевод со ссылкой на первоисточник — то же, что ежедневно делают израильские русскоязычные СМИ.
- **Фото** не копируются: вставляются по ссылке с источника (og:image) с указанием автора — стандартная практика превью. По требованию правообладателя убираются одной строкой.
- Информация справочная, первоисточник — Минздрав Израиля. (Не юридическая консультация.)

## Честные ограничения

- **gov.il за Cloudflare:** прямой опрос из датацентров часто блокируется, поэтому основной источник — Google News RSS (те же объявления в зеркалах прессы + сам gov.il в Google News). Прямой опрос остаётся в коде: если блок исчезнет — заработает сам, без изменений.
- **Словарь:** типовые причины покрыты; нестандартные честно уходят с пометкой «смотрите оригинал». Заведёлась новая формулировка — добавляется одна строчка в `src/hebrew.py`.
- **Номера партий:** в заголовках новостей их нет; карточка даёт ссылку на источник с полным списком. Энричмент (дотянуть тело статьи) — дорожная карта.
- Это не юридический и не медицинский совет; первоисточник — Минздрав Израиля.

## Интеграция с вашим сайтом (у вас GitHub Pages — самый чистый путь)

**Шаг 1. Включить Pages у репозитория бота:** Settings → Pages → Source: **GitHub Actions**. Всё.
Дальше автоматически: каждые 20 минут бот проверяет ленту; появилось новое → пуш в Telegram → коммит базы → **каталог сам публикуется** на `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПО/`.

**Шаг 2. Виджет на основном сайте.** GitHub Pages отдаёт данные с открытым CORS, поэтому основной сайт может жить в другом репозитории — просто вставьте перед `</body>` (файл `widget/otzyvy-widget.js` скопируйте в основной репозиторий, например в `/js/`):
```html
<div id="otzyvy-widget"></div>
<script src="/js/otzyvy-widget.js"
        data-src="https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПО/otzyvy.json"
        data-base="https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПО/"
        data-bot="https://t.me/otzyv_israel"></script>
```
Виджет берёт JSON прямо с Pages бота (обновляется сам), ищет по названию и штрих-коду, ссылает на карточки каталога.

**Шаг 3 (опция). Свой поддомен:** добавьте в репозиторий файл `site/CNAME` со строкой `otzyvy.vashsite.ru` + CNAME-запись в DNS — каталог будет на вашем домене (лучший SEO). Тогда же поменяйте data-src/data-base виджета на поддомен.

**Важно для SEO:** чтобы Google быстрее нашёл каталог, добавьте в корень основного сайта ссылку на него («Отзывы Израиль — проверить продукт») и в robots/sitemap основной домен не запрещает поддомен.

4. Предложение ленты русскоязычным СМИ как источника (обратная ссылка = рост).
